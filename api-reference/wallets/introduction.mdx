Quidax lets you programmatically create and manage crypto and fiat wallets for your users: generate addresses, watch deposits arrive, send funds out, and trade — all for a parent account or any sub-account in its tree.

## What you can do

- Create wallets across [50+ supported currencies](/wallets/coverage).
- Fetch wallets and generate deposit addresses for a user.
- Send crypto out on-chain, or move it between your own accounts.
- Place and manage trades and instant swaps.

## Base URL

```
https://openapi.quidax.io/exchange-open-api/api/v1
```

Every path on these pages is relative to that root.

## Authentication

Send your secret key as a bearer token on every request.

```bash
curl 'https://openapi.quidax.io/exchange-open-api/api/v1/users/me' \
  -H 'accept: application/json' \
  -H "Authorization: Bearer $QUIDAX_SECRET_KEY"
```

One key reaches every sub-account in your tree. Endpoints take a `user_id` path segment — use `me` for your parent account, or a sub-account's ID to act on that sub-account.
